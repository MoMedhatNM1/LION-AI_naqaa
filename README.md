# LION AI — نظام إدارة نقاء كلين

**NAQAA CLEAN MANAGEMENT SYSTEM**

نظام إداري وتقني فاخر بواجهة مستقبلية زجاجية (Liquid Glass)، عربي بالكامل (RTL)،
مبني لإدارة شركة **نقاء كلين | NAQAA CLEAN** ومصنع فيديوهاتها.

> LION AI هو النظام الإداري والتقني، ونقاء كلين هي الشركة الوحيدة داخل النظام.

## الهوية

- واجهة فاتحة فاخرة: أبيض ثلجي، فضّي، وذهبي هادئ.
- الأسد عنصر أساسي في الشعار والواجهة الرئيسية وكعلامة مائية.
- شعار وهوية **نقاء كلين** داخل بطاقة الشركة والأقسام التشغيلية.
- الموقع: [naqaacleanksa.com](https://naqaacleanksa.com)

## الأقسام

| القسم | الوصف |
| --- | --- |
| الرئيسية | لوحة تحكم شاملة مع Hero الأسد وبطاقة نقاء |
| نظرة عامة على نقاء | ملف الشركة، الخدمات، مواقع التواصل |
| مصنع فيديوهات نقاء | خط إنتاج الفيديو من الرفع حتى النشر |
| حالة المصنع | مراقبة الأداء والموارد في الوقت الحقيقي |
| رفع الفيديو | رفع الفيديو مع اختيار الجمل تلقائيًا/يدويًا |
| اختيار الجمل | اختيار الجمل تلقائيًا بالذكاء أو يدويًا |
| مكتبة الجمل | إدارة الجمل (إضافة/حذف/تفضيل/بحث) |
| الفيديوهات السابقة | أرشيف الفيديوهات المنتجة |
| المهام والتطويرات | لوحة كانبان للمهام |
| إدارة المحتوى | خطة المحتوى عبر المنصات |
| الشعار والتواصل | إعدادات هوية وبيانات نقاء |
| الإعدادات | تفضيلات النظام |

## التقنيات

React 18 · TypeScript · Vite · Tailwind CSS · Zustand · React Router · React Hook Form + Zod.

مستوحى بشكل محدود من مبادئ Magic UI و Liquefy UI (بطاقات زجاجية وحركات دخول راقية)
دون نسخ أي مكتبة كاملة.

## التشغيل

```bash
npm install
npm run dev      # التطوير
npm run build    # بناء الإنتاج
npm run preview  # معاينة البناء
npm run lint     # الفحص
```
